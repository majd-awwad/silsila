# ربط OpenRouter (الشات + الصوت)

## ليش الشات والصوت ضعاف هلأ
بدون مفتاح التطبيق بيشتغل **بالوضع الاحتياطي**: قواعد ثابتة بدل موديل لغوي، وصوت المتصفح العربي (مش فلسطيني).

## الخطوات (أنتم بتعملوها، فيها حساب ودفع)
1. ادخلوا على https://openrouter.ai وسجّلوا حساب.
2. من صفحة Credits ضيفوا رصيد صغير (٥ دولار كبداية).
3. من https://openrouter.ai/keys اعملوا مفتاح جديد، وحطّوا له حد صرف (Credit limit).
4. افتحوا الملف `.env.local` بمجلد المشروع، والصقوا المفتاح بعد `OPENROUTER_API_KEY=` واحفظوا. **لا تبعتوا المفتاح بأي محادثة.**
5. سكّروا السيرفر إذا شغّال (Ctrl+C) وشغّلوه من جديد: `npm run dev`. فوق لازم يكتب «ذكاء اصطناعي متصل».

## اختيار صوت نور
```
npm run voice:samples
```
بيعمل `voice-samples/index.html`: نفس ٣ جمل فلسطينية بعدة موديلات وأصوات. اسمعوها كلكم، وحطّوا الفايز بـ`TTS_MODEL` و`TTS_VOICE`.

## قياس فهم لهجتنا (المايك)
حطّوا تسجيلات **بأصواتكم أنتم** بمجلد `voice-in/` (مثلاً `1.m4a`) ومع كل واحد ملف `1.txt` فيه الكلام بالضبط. نفس الأمر بيطبع نسبة خطأ الكلمات (WER، الأقل أحسن) لكل موديل. حطّوا الفايز بـ`STT_MODEL`. ما بنسجّل أطفال حقيقيين.

## اختيار موديل الشات
```
npm run eval:models -- --models=google/gemini-3.8-flash,anthropic/claude-haiku-5.5,openai/gpt-5.4-mini,google/gemini-3.1-flash-lite,qwen/qwen3.8-flash
```
جدول: الدقة، التسريب (لازم ٠)، الزمن، التكلفة لكل ١٠٠٠ تشخيص. الفايز بينحط بـ`LLM_MODEL`، والجدول هو تبرير الاختيار قدّام الحكّام.

## إذا إشي فشل
رسالة الخطأ بتطلع بنافذة السيرفر (`[tts]` / `[stt]`). المايك الحقيقي من المتصفح لسا ما انجرّب بصوت إنسان.
